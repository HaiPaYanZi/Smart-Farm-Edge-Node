## 三个重点抽查(影响设计决策,务必确认)

1. **CH340 的 TXD/RXD 到底接 PA2/PA3 还是 PA9/PA10?**
   → 接 PA2/3:RS485 干净,调试口共存可用(最优)
   → 接 PA9/10:RS485 方案要改(换 UART4 或拆芯片)
2. **PC13 的 LED 是"高电平点亮"还是"低电平点亮"?**
   → 决定代码里 SET/RESET 哪一个是亮
3. **PC14/15 上 32.768K 晶振真的焊了吗?**
   → 没焊:PC14/15 就是两个自由 GPIO,LED 全用上,不用改设计
   → 焊了:LED_上联/运行改到其他空闲 PC 口(PC0~PC12 中挑)

## 实物核对结果(2026-08-06,亲眼看原理图)

**板上有外设的引脚(共 6 处):**
- PA8 → 板载 LED2(低电平点亮)
- PA9 → CH340G RXD / PA10 → CH340G TXD(USART1 被占!)
- PA11/PA12 → USB(TYPE-C:USBD-/USBD+)
- PC8 → SW2 按键 / PC9 → SW3 按键
- WK-UP 按键 → PA0
- 8M 晶振(PD0/PD1)+ 32.768K 晶振(PC14/PC15)均焊接 → **PC14/15 不可用**
- LED 共 2 个:PA8(LED2,低有效)+ 电源灯(直连 3.3V,不占引脚)

**其余引脚全部干净,仅排针引出。**
