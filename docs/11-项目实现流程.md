## 节点1：模块平台开发（软件全功能，面包板）

> 全部软件功能在此节点完成，硬件用面包板+模块。**本节点是项目主体。**

| 子节点 | 任务 | 产出物 | 出口条件 |
|---|---|---|---|
| 1.1 显示与调试 | OLED(SSD1306) 驱动、三页界面框架、调试命令处理 | ssd1306.c、调试口可交互 | OLED 显示正常，串口命令可用 |
| 1.2 传感器采集 | 软件 I2C 驱动 → AHT20/BH1750；ADC → 土壤湿度；滑动滤波+标定 | aht20.c/bh1750.c/bsp_adc.c | 三路数据 OLED 实时显示，与比对仪表偏差达标（F01~F03） |
| 1.3 执行器开环 | TIM3 双路 PWM（风机/补光）、继电器、蜂鸣器、霍尔 EXTI 测速 | bsp_pwm.c/bsp_gpio.c/测速模块 | 手动命令驱动各执行器正常（F04）；转速读数合理 |
| 1.4 控制核心 | PID（抗积分饱和/限幅/滞回）、规则引擎（补光/灌溉）、堵转检测 | pid.c/task_control.c | 温度 PID 闭环稳态 ≤±1℃（F05~F08）；堵转触发报警（F14） |
| 1.5 RTOS 化 | FreeRTOS 六任务化：采集/控制/反馈/Modbus/显示/日志；队列+互斥+快照区 | 全部 task_*.c | 任务化后行为与裸机一致，优先级抢占正确（PERF1/2 达标） |
| 1.6 存储与 Modbus | FatFS+SD 日志；FreeModbus 从机移植（寄存器表按《06》） | fatfs 移植/modbus 移植 | SD 日志格式正确（F12）；ModbusPoll 读写全部寄存器通过（F10/F11） |
| 1.7 OTA 机制 | Bootloader 工程（分区/跳转/回滚）、升级协议栈、PC 升级工具（串口直连） | boot/ 工程、tools/ota_tool.py | 升级/断电回滚/坏固件拒绝全部通过（E07/E08、PERF9） |

**节点1 整体出口条件**：功能用例 F01~F15 全部通过；边界用例 B 系列通过；异常用例 E01~E06 通过。

## 节点2：自研电路验证（洞洞板，逐块替换模块）

> 参照《08-硬件设计说明》§3 顺序，**每块电路验证通过才替换对应模块，未验证不上底板。**

| 子节点 | 任务 | 验证方法 | 出口条件 |

**节点2 整体出口条件**：H01~H08 硬件用例全部通过；模块平台功能在"替换后的自研电路"上全量回归（F 系列重跑）。

## 5. 节点依赖关系与并行性

```
节点0 ──┬──→ 节点1（主线，不可并行）
        └──→ （并行）节点2 的洞洞板焊接可在 1.6 之后提前开始
节点1.7 OTA ── 依赖 1.6 Modbus/存储（共享受控框架），不依赖节点2/3
节点3 打样等待期 ── 可并行推进 4.2 中转设计 / 文档补全
节点4.1 依赖：节点3 整机 + GEC6818 侧配置
```

**关键路径**：节点0 → 1 → 2 → 3 → 4.1 → 4.3。其余节点可插入并行。
