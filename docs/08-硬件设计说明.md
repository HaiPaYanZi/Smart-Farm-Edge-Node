## 1. 硬件架构

```
12V输入 ──[防反接+保险丝]──→ 12V→5V(MP1584自研) ──→ 5V母线
                                                     ├─→ 核心板5V引脚 → 板载AMS1117 → 3.3V
                                                     ├─→ 继电器模块(5V)
                                                     └─→ 蜂鸣器电路(5V, S8050开关)
3.3V母线(核心板提供) ── MAX3485 / SD卡 / 软件I2C上拉 / DRV8833逻辑侧

外设接口(排针)：
  RS485端子(2P) │ 风机PWM+方向 │ 补光PWM │ 继电器输出端子 │ 霍尔输入 │
  I2C母线(4P×3) │ SD卡座 │ ADC(PA0) │ 扩展排针(CAN/串口)
```

**设计原则**：底板只做"电源 + 接口转换 + 自研电路"，主控用核心板，传感器/OLED 用模块。全排针/模块座连接，优先可插拔。

## 2. 自研电路清单（参照模块设计，逐块验证）

### 2.1 12V→5V 降压（参考 MP1584 模块电路）

| 元件 | 规格 | 作用 |
|---|---|---|
| U1 | MP1584（4.5~28V 输入） | 同步降压 3A |
| L1 | 10μH 功率电感 | 储能 |
| D1 | SS34 肖特基（若为非同步拓扑） | 续流 |
| R1/R2 | 反馈分压（Vout=0.8×(1+R1/R2)） | 设定 5V |
| C_in/C_out | 22μF/47μF 陶瓷 | 输入/输出滤波 |
| EN | 10K 上拉 | 使能 |

**要点**：GND 铺地回走输入电容，反馈走线远离电感（防噪声）；输出 5V 处加 LED 指示。

### 2.2 5V→3.3V LDO（AMS1117-3.3，核心板已有，底板预留）

- 底板预留 AMS1117-3.3 电路（输入 5V 输出 3.3V）作备用；正常由核心板 LDO 供电，**两者不可同时供电（选贴/跳线）**。

### 2.3 蜂鸣器驱动电路（S8050 三极管开关）

```
GPIO(PB4) ──R1 1K──┤B        C──蜂鸣器(5V 有源)──VCC5V
                    │        │
                  S8050      E──GND
```
- R2 = 10K 基极下拉（GPIO 上电不确定期间静音）；
- 蜂鸣器并联反向续流二极管 D2（1N4148）吸收关断反峰。

### 2.4 RS485 电路（MAX3485）

```
USART1_TX(PA9) → DI
USART1_RX(PA10) ← RO
DE(PA8) → DE + /RE 并联
A/B 端子 → 120Ω 终端匹配电阻（跳线选择）+ TVS(SMBJ6.0CA) 保护
3.3V 供电（MAX3485 是 3.3V 器件）
```

### 2.5 电机驱动电路（DRV8833 芯片，参照模块）

```
IN1 ← 风机PWM(PA6)    AOUT1/2 → 风机
IN2 ← GPIO(PA4,方向/使能)  AOUT → 风机
VM ← 5V 或 12V（按风机选型，跳线选择）
STBY ← 3.3V（高有效）
```
- 补光 PWM（PA7）走第二路 IN3/IN4（同一芯片双 H 桥）；
- VM 端并 100μF 电解电容 + 0.1μF 陶瓷（电机瞬态电流）；
- **若自研 H 桥遇阻，先用 DRV8833 模块调通软件，再换芯片电路（模块→芯片 替代顺序）**。

### 2.6 继电器驱动（S8050 + 续流二极管，或直接用成品模块）

```
GPIO(PB0) → R 1K → S8050 → 继电器线圈(5V) ← VCC5V
继电器线圈并联 1N4148（续流，方向必须正确：阴接VCC）
触点输出：端子 2P（常开），外接水泵
```

### 2.7 霍尔测速输入（开漏/推挽兼容）

```
霍尔模块输出 → R 10K 上拉到 3.3V（若模块为开漏） → PB1(EXTI1)
模块 VCC=3.3V（勿接 5V）
```

### 2.8 软件 I2C 母线

```
PB6(SCL)/PB7(SDA) → 4.7K×2 上拉 → 3.3V
排针 4P×3 位：AHT20 / BH1750 / OLED 并联挂载
```

## 3. 模块调通 → 自研电路验证顺序（关键！）

**每步验证通过才进入下一步，否则不推进：**

| 步骤 | 内容 | 验证方法 |
|---|---|---|
| 1 | 核心板 + 面包板 + 全部模块 | 软件全功能跑通（采集/控制/Modbus/OTA） |
| 2 | 洞洞板焊"蜂鸣器电路" | 按键/指令触发鸣叫，测关断无响声 |
| 3 | 洞洞板焊"12V→5V 降压" | 万用表 5V±3%，满载温升 <40℃ |
| 4 | 洞洞板焊"MAX3485 电路" | USB转RS485 与 PC 收发正常，Modbus 工具读寄存器 |
| 5 | 洞洞板焊"DRV8833 电路" | 风机调速平滑、无啸叫；堵转测试 |
| 6 | 洞洞板焊"继电器电路" | 动作/复位正常，续流二极管方向正确 |
| 7 | 全部自研电路合成底板 Layout | 见 §5 评审清单 |

**验证失败即查：先查电源电压，再查 GPIO 电平，用示波器/逻辑分析仪抓时序。**

## 4. 底板 Layout 要点（嘉立创EDA，2 层板）

| 项 | 要求 |
|---|---|
| 板框 | ≤100×100mm（免费打样尺寸内，每月 2 次） |
| 线宽/间距 | 电源线 ≥20mil，信号线 ≥6mil，间距 ≥6mil |
| 电源走线 | 12V/5V 加宽走线；GND 铺地回走，电源回路短粗 |
| 分区 | 强电（继电器触点/电机）与弱电（3.3V 逻辑）分区域，物理隔离 |
| 485 | A/B 差分对等长走线；120Ω 匹配跳线 |
| 接口 | 所有排针丝印标注功能名；电源反接保护（肖特基串入 + 保险丝） |
| 焊接 | 直插为主（排母/端子/模块座），自研 SMD 元件选 0603/0805 手焊友好 |
