## 1. 引言

### 1.1 目的

本文档定义"温室环境智能控制节点"的功能需求、性能指标、接口需求、环境约束与验收标准，作为设计、开发、测试与验收的唯一依据。

### 1.2 范围

本节点部署于温室/大棚现场，实现环境参数感知、本地闭环控制（PID 风机调速 + 规则引擎多执行器联动）、数据本地存储、Modbus 上联与 OTA 远程升级，支持断网自治运行。本阶段范围为单节点，不含多节点组网（预留扩展）。

### 1.3 术语

| 术语 | 含义 |
|---|---|
| 边缘自治 | 节点在脱离上联网络时，本地控制逻辑仍独立运行 |
| 安全态 | 系统检测到故障后进入的受控状态（风机安全转速/执行器断电） |
| OTA | 通过下载通道完成的固件升级（Over The Air） |
| 堵转 | 电机有 PWM 输出但实际转速接近 0 的故障状态 |

## 2. 项目概述

### 2.1 背景

设施农业对温室内环境（温湿度、光照、土壤水分）的自动调节有明确需求。传统方案依赖"采集器 + 人工决策 + 手动操作"，本节点将采集、决策、执行下沉到现场，构成感知执行层，为上层 HMI 与云平台提供数据与受控能力。

### 2.2 系统定位（三层架构中的角色）

```
┌─────────────────────────────────────────────┐
│  云平台层：PC/Web 服务器（远程监控、告警推送）  │
├─────────────────────────────────────────────┤
│  边缘交互层：GEC6818 Linux HMI（Modbus 主机） │
├─────────────────────────────────────────────┤
│  感知执行层：本节点（STM32，Modbus 从机）     │  ← 本文档定义
│  采集环境参数 + 本地控制 + 断网自治            │
└─────────────────────────────────────────────┘
```

### 2.3 部署场景

节点安装于温室大棚内，12V 直流供电（模拟太阳能/蓄电池场景），通过 RS485 总线与上层 HMI 连接。无人值守运行，可通过 OLED 现场查看，通过 Modbus 远程查看与配置。

## 3. 功能需求（FR）

### FR1 环境感知
| 编号 | 需求描述 | 来源 |
|---|---|---|
| FR1.1 | 采集空气温度，量程 -20℃ ~ +60℃，分辨率 0.1℃ | AHT20 |
| FR1.2 | 采集空气湿度，量程 0% ~ 100%RH，分辨率 0.1%RH | AHT20 |
| FR1.3 | 采集光照强度，量程 0 ~ 65535 lx | BH1750 |
| FR1.4 | 采集土壤湿度（电容式），输出 0~100%（相对值） | ADC |
| FR1.5 | 采集风机实际转速（霍尔测速），单位 RPM | EXTI 计数 |

### FR2 执行控制
| 编号 | 需求描述 |
|---|---|
| FR2.1 | 风机 PWM 调速（20kHz），由温度 PID 闭环驱动，输出占空比 0~100% |
| FR2.2 | 补光灯 PWM 调光（20kHz），由光照规则驱动 |
| FR2.3 | 水泵继电器开关控制，由土壤湿度规则驱动 |
| FR2.4 | 蜂鸣器报警输出（故障/越限） |

### FR3 控制模式
| 编号 | 需求描述 |
|---|---|
| FR3.1 | 自动模式：规则引擎 + PID 闭环全自动运行 |
| FR3.2 | 手动模式：通过 Modbus 寄存器直接控制各执行器 |
| FR3.3 | 待机模式：停止全部控制输出，仅保持采集 |
| FR3.4 | 模式切换通过 Modbus 保持寄存器（40005）或 OLED 按键完成 |

### FR4 规则引擎（边缘自治核心）
| 编号 | 需求描述 |
|---|---|
| FR4.1 | 温度 PID：目标温度可配置，PID 参数（P/I/D）可远程整定 |
| FR4.2 | 滞回保护：温度低于（目标值-滞回下限）时风机彻底停转，防止频繁启停 |
| FR4.3 | 补光规则：光照低于阈值且温度正常时开补光，高于阈值+回差时关 |
| FR4.4 | 灌溉规则：土壤湿度低于阈值时开水泵，高于（阈值+回差）时关 |
| FR4.5 | 所有阈值、PID 参数、回差均存 Flash，可远程修改，掉电不丢失 |
| FR4.6 | 断网（上联断开）时以上规则全部继续运行（断网自治 ≥24h） |

### FR5 数据存储
| 编号 | 需求描述 |
|---|---|
| FR5.1 | 传感器数据、控制动作、报警事件按时间戳记录至 SD 卡（FATFS） |
| FR5.2 | 日志按天分文件，防文件无限增长（超大小自动滚动） |
| FR5.3 | 运行参数（PID/阈值/模式）存内部 Flash（模拟 NVS），掉电保持 |

### FR6 通信（Modbus 从机）
| 编号 | 需求描述 |
|---|---|
| FR6.1 | RS485 + Modbus RTU 从机，9600bps/8N1，从站地址 4（可配置） |
| FR6.2 | 支持功能码 03（读保持）、04（读输入）、06（写单个）、16（写多个） |
| FR6.3 | 寄存器映射见《Modbus 寄存器表》（C1 文档） |
| FR6.4 | 响应时间 < 100ms，满足上层 1s 轮询超时要求 |

### FR7 OTA 升级
| 编号 | 需求描述 |
|---|---|
| FR7.1 | Bootloader + A/B 双应用分区（A: 0x08010000，B: 0x08020000） |
| FR7.2 | 升级协议支持：握手、分包传输、CRC32 校验、失败重传 |
| FR7.3 | 校验失败或升级断电 → 自动回滚至原运行分区 |
| FR7.4 | 升级过程不影响当前运行分区（写入另一分区） |

### FR8 人机交互
| 编号 | 需求描述 |
|---|---|
| FR8.1 | OLED（0.96 寸 I2C）显示：温度/湿度/光照/土壤湿度/目标转速/实际转速/模式/故障状态 |
| FR8.2 | 三路状态 LED：电源/网络(上联)/运行 |
| FR8.3 | 串口调试口输出运行日志，波特率 115200（开发期 USART1+板载 CH340→USB-C；底板期 USART2） |

### FR9 报警
| 编号 | 需求描述 |
|---|---|
| FR9.1 | 故障分级：轻微（可重试）/严重（降级运行）/致命（停机保护） |
| FR9.2 | 报警事件：传感器失效、堵转、上联断线、SD 卡写入失败 |
| FR9.3 | 报警输出：蜂鸣器 + OLED 提示 + Modbus 状态位上报 |

## 4. 性能指标（量化验收标准）

| 编号 | 指标 | 指标值 | 验收方法 |
|---|---|---|---|
| PERF1 | 传感器采集周期 | 200ms ± 20% | 逻辑分析仪/日志时间戳 |
| PERF2 | 控制周期（PID 计算） | 100ms ± 20% | 同上 |
| PERF3 | PID 温度稳态误差 | ≤ ±1℃（目标 ±5℃ 内） | 恒温环境数据记录 |
| PERF4 | Modbus 响应时间 | < 100ms | 主机侧测量 |
| PERF5 | 断网自治时长 | ≥ 24h 无异常 | 断开上联连续运行测试 |
| PERF6 | 掉电重启恢复时间 | < 30s 恢复运行 | 掉电-上电实测 |
| PERF7 | 传感器失效检测时间 | < 5s 进入安全态 | 故障注入测试 |
| PERF8 | 日志连续写入 24h 零丢失 | 100% | 对比记录数 |
| PERF9 | 固件升级 100KB 传输成功率 | ≥ 99%（重传机制下） | 重复升级测试 |
| PERF10 | 看门狗复位恢复 | < 2s | 注入死循环测试 |

## 5. 接口需求

### 5.1 电气接口

| 接口 | 引脚 | 说明 |
|---|---|---|
| RS485 A/B | USART3 PB10/PB11 + MAX3485 | DE=PC0，9600bps（V1.1 实物适配：原 PA9/10 被板载 CH340 占用） |
| 风机 PWM | PA6（TIM3_CH1） | 20kHz |
| 补光 PWM | PA7（TIM3_CH2） | 20kHz |
| 霍尔测速 | PB1（EXTI1） | 上升沿计数 |
| 水泵继电器 | PB0 | 高电平闭合，上电默认断开 |
| 蜂鸣器 | PB4 | 高电平鸣叫 |
| I2C 总线（软件） | PB6(SCL)/PB7(SDA) | AHT20/BH1750/OLED 共用 |
| SD 卡 | SPI2 PB13/14/15 + CS PB12 | 400kHz 初始化后提速 |
| 土壤湿度 | PA1（ADC1_IN1） | 0~3.3V 模拟量（V1.1 实物适配：原 PA0 被 WK_UP 按键占用） |
| 掉电检测（V1.1 新增预留） | PC2（ADC1_IN12） | 12V 分压采样 |
| 调试串口 | 开发期 USART1 PA9/PA10（板载 CH340→USB-C）；底板期 USART2 PA2/PA3 | 115200 |

### 5.2 电源接口

| 接口 | 参数 |
|---|---|
| 输入 | 12V DC ±10%（模拟太阳能/蓄电池场景） |
| 板载降压 | 12V→5V（MP1584 参考电路，自研）→ 3.3V（AMS1117） |
| 功耗预算 | 整机 ≤ 3W（含风机/继电器） |

### 5.3 通信接口汇总

| 接口 | 协议 | 用途 |
|---|---|---|
| RS485 | Modbus RTU 从机 | 上联数据/控制 |
| 串口 | 自定义调试协议 | 开发调试 |
| OTA 通道 | 自定义升级协议（RS485 或 PC 直连） | 固件升级 |
| 扩展预留 | CAN1（PB8/PB9） | 多节点组网（后续版本） |

## 7. 安全需求（工业安全哲学）

| 编号 | 需求描述 |
|---|---|
| SAF1 | 继电器上电默认断开，禁止上电瞬间误动作 |
| SAF2 | 安全态策略：风机故障→保持安全转速（30%）；水泵/继电器故障→断电；所有故障上报 |
| SAF3 | 传感器失效（连续 5 次采集失败）→ 5s 内进入安全态 |
| SAF4 | 堵转检测：PWM>30% 且 3s 内转速≈0 → 停机+报警+10s 后自动重试 1 次 |
| SAF5 | 独立看门狗（IWDG）+ FreeRTOS 任务级看门狗（每任务独立 feed 超时检测） |
| SAF6 | 掉电检测：输入电压跌落阈值 → 停止执行器输出 → 保存运行模式到 Flash |
| SAF7 | 电源防反接 + 保险丝 + 输出接口 TVS（底板设计约束） |
| SAF8 | OTA 升级失败不得影响当前运行分区（A/B 机制保证） |

## 8. 验收标准

1. 全部功能需求 FR1~FR9 实现并可演示；
2. 性能指标 PERF1~PERF10 全部达标（见测试报告 D2）；
3. 安全需求 SAF1~SAF8 通过故障注入验证（拔传感器/堵转/断电/OTA 中断）；
4. 连续 24h 跑机无死机、无日志丢失；
5. 全部文档交付：本规格书 + 设计文档 + 测试用例与报告 + 操作手册。
