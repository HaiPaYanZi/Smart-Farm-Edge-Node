| 项 | 规格 |
|---|---|
| MCU | STM32F103RCT6（Cortex-M3, 72MHz, 256KB Flash, 48KB RAM, LQFP64） |
| 传感器 | AHT20（I2C 0x38）、BH1750（I2C 0x23）、电容式土壤湿度（ADC） |
| 执行器 | 直流风机（DRV8833 驱动，PWM 调速）、补光灯（PWM）、水泵（继电器）、蜂鸣器 |
| 通信 | MAX3485 + RS485（Modbus 从机，USART3）、USART1 调试口（开发期，板载 CH340→USB-C）/ USART2（底板期） |
| 存储 | MicroSD（SPI2 + FATFS）、内部 Flash（参数） |

| 电源 | 12V 输入 → 5V（MP1584 自研电路）→ 3.3V（AMS1117） |

## 3. 软件架构（FreeRTOS）

### 3.1 任务划分与优先级

| 任务 | 优先级 | 周期/触发 | 职责 | 主要交互 |
|---|---|---|---|---|
| 反馈任务 | 最高(6) | 外部中断+队列 | 霍尔脉冲计数→转速计算、堵转判定辅助 | 发队列给控制任务 |
| 采集任务 | 高(5) | 200ms 定时 | 传感器读取、滤波、标定、快照更新 | 写快照区(临界区) |
| 控制任务 | 中高(4) | 100ms 定时 | 规则引擎、PID 计算、执行器输出、故障管理 | 读快照、发 PWM/GPIO、状态机 |
| Modbus 任务 | 中(3) | 串口事件 | 帧解析、寄存器读写、远程控制 | 读写快照/参数区(互斥) |
| 显示任务 | 低(2) | 500ms | OLED 刷新 | 读快照(只读) |
| 日志任务 | 低(1) | 事件触发 | SD 卡批量写入、参数保存 | 收日志队列、存 Flash |

**优先级设计理由**：
- 反馈最高：霍尔脉冲不可丢，丢失导致转速计算错误；
- 控制次之：实时性要求（100ms 周期），但不允许抢占反馈；
- Modbus 中：响应 <100ms 满足轮询超时，可被采集/控制抢占；
- 显示/日志最低：可被任意任务抢占，空闲时执行。

### 3.2 任务间通信机制

| 机制 | 用途 | 说明 |
|---|---|---|
| 队列（Queue） | 霍尔脉冲→反馈任务；转速→控制任务；日志→日志任务 | 定长，生产者/消费者 |
| 互斥量（Mutex） | Modbus 读写参数区/快照区 | 保护多字节结构体读写 |
| 临界区 | 快照区单字更新 | 采集任务写，控制任务读，进入临界区 |
| 事件组（可选） | 故障事件通知各任务 | FAULT 置位，显示/日志/Modbus 响应 |

## 4. 数据流设计

```
传感器 → 采集任务 ──滤波/标定──→ 环境快照区（温度/湿度/光照/土壤/转速）
                                    │
                                    ▼
                   控制任务: 规则引擎 → PID → 目标转速 → PWM → 电机 → 霍尔
                                    │                              │
                                    ▼                              ▼
                       执行器输出（风机/补光/水泵/蜂鸣器）       实际转速 → 快照区
                                                                    │
                    快照区 ←────── 显示任务(OLED) / Modbus任务(上报)
                    日志队列 ←──── 控制动作/故障事件 → 日志任务 → SD卡
```

**核心原则**：
1. 数据统一进"环境快照区"，所有消费方（控制/显示/Modbus）只读快照，杜绝数据源不一致；
2. 控制任务产生的动作/故障事件进日志队列，日志任务批量落盘，不阻塞控制链路；
3. Modbus 读操作直接读快照（互斥保护），写操作写"参数区"（PID/阈值），由控制任务周期性加载——**控制逻辑不直接依赖 Modbus 中断上下文**。

## 5. 系统状态机

```
        ┌────────┐  上电自检通过  ┌─────────┐
        │  INIT  │──────────────→│ STANDBY │
        └────────┘                └────┬────┘
        │自检失败(致命)                │ 模式=自动(40005)
        ▼                              ▼
     ┌──────┐ 条件解除        ┌──────────────┐
     │FAULT │←───────────────│     AUTO     │
     └──┬───┘  故障恢复        │ 规则引擎+PID │
        │ ▲                   └──────────────┘
        │ │ 致命故障/多次重试失败         │ 模式=手动(40005)
        │ └──────────────────┐            ▼
        │                    │     ┌──────────────┐
        │  模式=待机(40005)   │     │    MANUAL    │
        └────────────────────┴────→│ 直接控制执行器 │
              STANDBY 也可手动操作   └──────────────┘
```

| 状态 | 行为 |
|---|---|
| INIT | 硬件初始化、参数加载、外设自检；自检失败→FAULT（致命） |
| STANDBY | 仅采集与显示，无控制输出；可切换手动做执行器测试 |
| AUTO | 规则引擎（补光/灌溉）+ PID 闭环；正常运维状态 |
| MANUAL | 执行器由 Modbus/按键直接控制；控制任务跳过 PID |
| FAULT | 按故障等级进入安全态（见 6.3）；故障解除且重试后回 AUTO/STANDBY |
| RECOVERY | 故障恢复过渡态（如堵转 10s 重试），成功后回 AUTO |

**切换动作与模式字**（状态位上报 Modbus 30007）：自动=0x01、手动=0x02、待机=0x04、故障=0x08、恢复=0x10。

## 6. 可靠性设计

### 6.1 看门狗

| 看门狗 | 机制 |
|---|---|
| IWDG（独立） | 主循环/空闲钩子喂狗，超时 1s 硬件复位 |
| 任务级看门狗 | 每个任务周期内 feed 自己的计数器，控制任务每 100ms 检查所有任务计数器，任一超时→FAULT(致命)→复位 |

### 6.2 掉电检测与恢复

- ADC 监视 12V 输入电压（分压采样）；
- 电压 < 9V 持续 50ms → 判定掉电 → 停止执行器输出 → 保存运行模式到 Flash → 等待复位；
- 上电恢复：读取上次模式，30s 内恢复到断点前运行状态（PERF6）。

### 6.3 故障分级与安全态

| 等级 | 故障 | 安全动作 | 恢复 |
|---|---|---|---|
| 轻微 | 上联断线、SD 写失败 | 降级运行（断网自治），记录报警 | 自动 |
| 严重 | 堵转、传感器失效 | 风机安全转速 30% / 执行器断电，蜂鸣器报警 | 10s 自动重试 1 次 |
| 致命 | 看门狗超时、参数区损坏 | 停止全部输出，复位后进待机 | 人工干预 |

**安全态哲学**（评审已确认）：农业场景"通风缺失"风险低于"浇水过量"——风机故障保持安全转速（30%），水泵/继电器故障直接断电，全部报警上报。

### 6.4 OTA 可靠性

- A/B 双分区 + 固件头（magic+版本+长度+CRC32）；
- Boot 校验失败自动回滚；升级中断电不损坏当前运行分区；
- 详细协议见《通信协议规范》。

## 7. 关键设计决策记录（ADR）

| 编号 | 决策 | 理由 |
|---|---|---|
| ADR-01 | 软件 I2C 而非硬件 I2C | F103 硬件 I2C 存在总线锁死 BUG；软件 I2C 可移植、易调试（示波器抓引脚即可） |
| ADR-02 | Modbus 做从机而非主机 | 上联 GEC6818 已是主机；从机实现简单且寄存器模型天然适配"节点上报+远程配置" |
| ADR-03 | FreeRTOS 而非裸机 | 6 个并发职责单元；CubeMX 集成成本低；岗位 JD 标配 |
| ADR-04 | PID 输出目标转速而非直接 PWM | 语义清晰（转速可显示、可回读），为后续"转速内环"预留 |
| ADR-05 | 风机/补光共用 TIM3 双通道 | 单定时器管理同频 PWM，简化配置；中断共享 |
| ADR-06 | SD 卡用 SPI2 | SPI1(PA5/6/7) 被 PWM 占用，SPI2 引脚无冲突 |
| ADR-07 | 换用 F103RCT6 而非 C8T6 | OTA A/B 双区需 256KB Flash；C8T6 标称 64KB 放不下；RCT6 另有 CAN 预留 |
| ADR-08 | 传感器失效按"连续 5 次"判定 | 单次失败可能是总线瞬时干扰，5 次(1s)容错避免误入安全态 |
| ADR-09 | 上电继电器默认断开 | GPIO 上电状态不确定，防误动作（SAF1） |
| ADR-10 | 快照双缓冲 + 互斥 | 采集(写)与控制/Modbus(读)并发，保证数据原子性 |
