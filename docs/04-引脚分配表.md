## 2. 外设冲突检查表（评审记录）

| 检查项 | 结果 |
|---|---|
| USART1（PA9/10）与 USB（PA11/12） | ✅ 不冲突，USB 未用 |
| TIM3_CH1/CH2（PA6/7）与 SPI1（PA5/6/7） | ⚠️ **冲突** → SD 卡改走 SPI2（PB13/14/15），已解决 |
| TIM3（PA6/7）与 ADC 通道（PA6/7 是 ADC1_IN6/7） | ✅ 复用功能不共存，PWM 与 ADC 二选一，本设计 PWM |
| PB3/PB4 与 JTAG | ⚠️ **需在代码中关 JTAG**（见 §3），PB4 作蜂鸣器 |
| PC14/PC15 与 LSE 振荡器 | ⚠️ **需关闭 LSE 功能**（HAL 默认不使能，确认即可），作 LED |
| PA15 与 JTDI | ⚠️ 关 JTAG 后可用作 KEY1 |
| PB6/PB7 与 I2C1 硬件 | ✅ 软件 I2C，仅用 GPIO 功能 |
| EXTI1（PB1）与 ADC1_IN9 | ✅ 复用不冲突 |
| SPI2 与 CAN（PB13/PB14 也是 CAN2_RX/TX） | ⚠️ **CAN2 不可用**（F103 CAN2 依赖 CAN1，无 CAN1 分配）；CAN1 在 PB8/PB9，无冲突 ✅ |
| 定时器需求 | TIM3（PWM 双通道）、TIM4（预留）、SysTick（RTOS）— 资源充足 |
| ADC 通道 | 仅用 ADC1_IN0（PA0），可扩展 IN1~IN7 |

## 3. 特殊引脚说明（三大坑）

### 3.1 JTAG 释放（PB3/PB4/PA15）

```c
// 使能 AFIO 时钟后关闭 JTAG，保留 SWD
__HAL_AFIO_REMAP_ENABLE(JTAGDIS);  // 或 RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO)
// 关闭后：PB3/PB4/PA15 释放为 GPIO，SWD(PA13/14) 不受影响
```

### 3.2 LSE 释放（PC14/PC15）

默认 HAL 工程未启用 LSE，PC14/PC15 可直接作 GPIO。**若使用 CubeMX 默认勾选了 LSE 需取消。**

### 3.3 BOOT0 与下载

核心板 BOOT0 跳线：开发阶段 BOOT0=0（从 Flash 启动）；若需串口 ISP 下载临时拉高。SWD 下载不受影响。

## 4. 底板排针定义（核心板接口约定）

底板排母按核心板双排 2.54mm 引脚顺序布局，与主控相关的引出：

| 排针分组 | 引出引脚 |
|---|---|
| 电源组 | 12V_IN、5V、3.3V、GND×3 |
| 485 组 | PA9、PA10、PA8（DE）、GND |
| 执行器组 | PA6（风机PWM）、PA7（补光PWM）、PB0（水泵）、PB4（蜂鸣器） |
| 传感器组 | PB6(SCL)、PB7(SDA)、3.3V、GND（I2C 三设备共用母线） |
| ADC 组 | PA0、3.3V、GND |
| 反馈组 | PB1（霍尔）、3.3V、GND |
| SD 组 | PB13/14/15、PB12、3.3V、GND |
| 扩展组 | PB8/PB9（CAN 预留）、KEY1/KEY2（PA15/PB5）、USART2（PA2/PA3） |

> 底板设计说明见《08-硬件设计说明.md》；**此表冻结后，底板 Layout 引脚一律以本表为准，改引脚须走变更评审。**
